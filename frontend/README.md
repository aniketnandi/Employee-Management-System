# Frontend

React 19 + TypeScript + Vite single-page app, styled with Tailwind CSS v4.
See the [root README](../README.md) for setup instructions.

```bash
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build
```

Set `VITE_API_URL` (see `.env.example`) to point at the backend; it defaults to `http://localhost:8000`.
